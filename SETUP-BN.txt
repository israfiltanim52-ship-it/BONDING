A. GitHub / Static App

B. Tanim AI চালু করা (Netlify Functions আবশ্যক)
গুরুত্বপূর্ণ: GitHub Pages static hosting Netlify Function চালাতে পারে না। Tanim AI endpoint চালাতে Netlify-তে এই project deploy করতে হবে।
১) Netlify-তে GitHub repository connect করে deploy করুন।
২) Site configuration → Environment variables-এ যোগ করুন:
   OPENAI_API_KEY = আপনার OpenAI API key
   FIREBASE_SERVICE_ACCOUNT_JSON = Firebase Admin service account JSON-এর সম্পূর্ণ JSON string
   OPENAI_MODEL = gpt-4.1-mini (ঐচ্ছিক; না দিলেও default ব্যবহার হবে)
৩) Firebase Console/Google Cloud থেকে service account তৈরি করার আগে project owner-এর অনুমতি নিন। JSON key অত্যন্ত গোপন রাখুন; GitHub-এ আপলোড করবেন না।
৪) Environment variables যোগ করার পর Netlify-তে নতুন deploy করুন।
৫) লগইন করা BONDING account থেকে Tanim AI-তে text ও image পাঠিয়ে পরীক্ষা করুন।
৬) OpenAI API ব্যবহার অনুযায়ী বিল হতে পারে; API key-তে billing/usage limit নির্ধারণ করুন।

C. Communities
- Firestore Rules publish হওয়ার পর Public/Private community তৈরি ও public group join পরীক্ষা করুন।
- সাধারণ ব্যবহারকারী সর্বোচ্চ ৩টি community তৈরি করতে পারবেন।
- Private group join request পাঠানো যায়; owner approval UI এই build-এ এখনো অসম্পূর্ণ।

D. গুরুত্বপূর্ণ সীমাবদ্ধতা
