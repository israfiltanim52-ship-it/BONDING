BONDING Admin Dashboard — প্রাথমিক সেটআপ

১) ZIP Extract করে BONDING-main ফোল্ডারের ভেতরের ফাইলগুলো GitHub repository root-এ upload/replace করুন।
২) Firebase Console → Firestore Database → Rules-এ ZIP-এর firestore.rules সম্পূর্ণ বসিয়ে Publish করুন।
৩) Firebase Console → Authentication → Users-এ প্রতিষ্ঠাতা ইস্রাফিল তানিমের অ্যাকাউন্ট খুঁজে UID কপি করুন।
৪) Firestore Database → Data → Start collection: system; Document ID: adminConfig; Field: superAdminUid (string); Value: প্রতিষ্ঠাতার UID। এই ধাপটি শুধু প্রজেক্ট মালিক করবেন।
৫) অ্যাপ থেকে লগআউট/লগইন করুন; Settings-এ Admin Control Center দেখা যাবে। মোবাইলেও একইভাবে পরিচালনা করা যাবে।
৬) Super Admin Dashboard → Admin নিয়োগ থেকে নিবন্ধিত ইমেইল দিয়ে Admin, Moderator বা Verification Manager নিয়োগ করুন।

নিরাপত্তা: system/adminConfig ডকুমেন্টটি Firestore Rules দিয়ে client write থেকে বন্ধ। Founder UID ভুল দেবেন না। প্রথম Super Admin কেবল Firebase Console-এর মাধ্যমে সেট করতে হবে।

এই পর্যায়ে আছে: সদস্য তালিকা/সার্চ, পোস্ট মুছে moderation, ভেরিফিকেশন approve/reject, একাধিক admin role assign/revoke, admin action log। Auth account suspend/delete, reports workflow, comment moderation UI, analytics charts ও Cloud Functions এখনো পরবর্তী ধাপ।
